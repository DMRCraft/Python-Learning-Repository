## What is the point of tuples, if you can't change or add to them?

Simply, they are used for a grouped set of values that are guarenteed to not be changed <br>
E.g: cords = (10, 20) <br>
Another example: location = {
(10, 20): "Home",
(100, -20): "Village"
}
