# Iterables

Here is a practical list of some iterables. Note that there isn't a definite "list" of iterables, since any object can be made iterable by implementing the appropiate iteration method

- List [1, 2, 3]
- Tuple (1, 2, 3)
- Set {1, 2, 3}
- Dictionary {"A": 1, "B": 2, "C": 3}
- String | "Hello"
- Range | range(10)
- Bytes | b"hello"
